# 🌐 Portfólio Pessoal Responsivo

Site desenvolvido como projeto acadêmico com o objetivo de aplicar conceitos de HTML5, CSS3 e JavaScript, além de demonstrar conhecimentos em desenvolvimento web, design responsivo e organização de código.

## 📋 Sobre o Projeto

Este projeto consiste em um portfólio pessoal responsivo que apresenta informações profissionais, acadêmicas e pessoais de forma organizada e acessível.

O site foi desenvolvido utilizando tecnologias front-end puras, sem frameworks, priorizando boas práticas de desenvolvimento, responsividade e experiência do usuário.

---

## ✨ Funcionalidades

### 🎨 Personalização visual

- Troca dinâmica de temas.
- Persistência do tema escolhido utilizando Local Storage.
- Temas disponíveis:
  - 🌷 Rosa (Padrão)
  - 🏖️ Praia
  - 🌊 Oceano
  - 🌿 Natureza
  - 🌙 Crepúsculo
  - 🌑 VS Code
  - 🦇 Dracula

### 📱 Responsividade

- Layout adaptável para desktop, tablet e dispositivos móveis.
- Menu responsivo para telas menores.
- Componentes ajustados automaticamente conforme o tamanho da tela.

### 🧭 Navegação

- Menu principal com submenu.
- Navegação por âncoras internas.
- Botão "Voltar ao topo".
- Tooltips nos seletores de tema.

### ⚡ Interatividade

- Exibição e ocultação de seções utilizando o elemento `<details>`.
- Cards expansíveis com informações sobre os gatos.
- Menu responsivo com JavaScript.
- Troca de temas em tempo real.

### 📩 Formulário de Contato

- Campos:
  - Nome
  - E-mail
  - Assunto
  - Mensagem
